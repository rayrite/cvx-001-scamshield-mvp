# Product Staged Research

Staged research workspace: product investigations, scam-shield checks, and parallel experiments.

## About this repo

This repository is the versioned home for research artifacts and experimental tooling:
investigation reports, checks and scans, and the small scripts that generate them.

## How this repo is worked on

- `main` is the stable spine — it should always be in a good state.
- New ideas start on a branch (`idea/…`, `exp/…`, `fix/…`) and are merged back when they pan out.
- Meaningful checkpoints are tagged (`v0.1`, `baseline-…`) so any point can be returned to.
